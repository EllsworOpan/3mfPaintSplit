FROM MODEL TO PRINT

A clean cut, with the color intact.

  1. Open a painted 3MF. Native PrusaSlicer MMU and Bambu / Orca AMS paint are read, including paint inside individual triangles. Unreadable optional palette settings are skipped automatically while retaining paint material numbers. Check the colors if a recovery warning appears. Invalid geometry, paint, or part roles still stop the import.
  2. Optionally position the plane. Choose X, Y, or Z, change the offset, or tilt and rotate the plane. Drag the arrow to move it; switch to Rotate for angle handles.
  3. Apply your cut. Both pieces remain. Select any piece and cut it again. Undo keeps the last 12 cuts.
  4. Save the painted 3MF. Choose your target slicer, import as separate objects, keep the same material slot order in your current printer setup, then orient each piece for printing. Exports contain no printer or print configuration. PrusaSlicer 3 uses a separate paint format; select its experimental export when using version 3.
  5. Convert colors to virtual extruders. Enable Use virtual extruders, choose 2–8 physical filament slots, and edit their numbered swatches to match your printer. Every exported color region gets its own editable virtual extruder and an estimated mixing recipe, even when two regions share a color. You can export immediately without making a cut. Select the matching printer in PrusaSlicer 2.9.6 or later and use File → Open Project to keep the virtual extruders. No printer or filament profiles are included.

New interior faces use the material you choose. Existing paint is resolved into colored mesh triangles, so exports can be larger than the original.

Printer profiles, supports, seams, modifiers, connectors, and variable layer settings are not carried over. Cuts require closed, consistently oriented meshes. This is a straight plane cutter; it does not add pins or joints.

All processing happens on your device. Use F to fit, C to cut, and Ctrl / ⌘ Z to undo.
